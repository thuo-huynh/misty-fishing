# Map nằm trên cloud Roblox, code và content nằm trong Git

Terrain và các công trình lớn không thể so sánh hay gộp thay đổi bằng Git, nên Builder dựng map trong Studio bằng Team Create và map được lưu trên cloud Roblox. Code (`src/`), content (`content/`) và model dùng chung (`models/*.rbxm`) nằm trong Git và được đồng bộ vào Studio bằng Rojo. Map và content chỉ gặp nhau qua Zone ID, và game kiểm tra sự khớp nhau này khi khởi động.
