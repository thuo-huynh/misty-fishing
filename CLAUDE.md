# Misty Fishing

Game câu cá trên Roblox (Luau + Rojo). Kế hoạch tổng thể ở `docs/plan.md`, thuật ngữ ở `GLOSSARY.md`, các quyết định lớn ở `docs/adr/`. Tài liệu viết bằng tiếng Việt.

## Agent skills

### Issue tracker

Công việc được theo dõi bằng GitHub Issues (dùng `gh` CLI). Xem `docs/agents/issue-tracker.md`.

### Triage labels

Dùng 5 nhãn mặc định: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. Xem `docs/agents/triage-labels.md`.

### Domain docs

Single-context: một `GLOSSARY.md` và `docs/adr/` ở thư mục gốc. Xem `docs/agents/domain.md`.
